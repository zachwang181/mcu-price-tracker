MCU 料號行情

追蹤 MCU 料號在通路與代理商的單價、交期，並對照原廠調價通知。通路目錄價由程式每天台灣時間 09:00 自動抓取；代理商報價、實際成交價和調價事件由人工記在 GitHub 上，每則附出處。點料號會開出卡片，看價格與交期走勢、每一筆報價，以及這家原廠的調價日。搜尋框能搜料號、製造商、備註和通路名稱。

料號

新增或刪除料號

在 GitHub 上編輯 data/parts_list.csv，一列一顆料號。欄位依序是 mpn,manufacturer,group,note：mpn 是完整原廠料號（含封裝後綴）、manufacturer 要跟調價事件的原廠寫法一致才對得上、group 填 intl（國際大廠）／cn（中國品牌）／tw（台灣品牌）、note 隨意。刪掉一整列就是不再追蹤那顆料號。

範例列：STM32F103C8T6,STMicroelectronics,intl,經典 Cortex-M3

編輯料號清單

籃子指數

每條「料號 × 來源 × 買量 × 幣別」的價格序列算出相鄰兩個日期的漲跌比，取幾何平均後逐日連乘，起點 = 100。某條序列沒有新資料時沿用前值（最多 45 天）。

調價事件

紅色日期是還沒生效的。原廠名稱跟料號的製造商寫法一致時，會畫在該料號的走勢圖上。

新增調價事件

在 GitHub 上編輯 data/notices.json，複製最後一筆 { … } 貼到後面，改成新的內容，記得兩筆之間要有逗號。欄位：id（自己取個不重複的短代號）、vendor（原廠，寫法要跟料號的 manufacturer 一致）、announced（發函日，不知道就留空字串）、effective（生效日，必填）、range（幅度，例 10–20% 或 未公布）、scope（範圍）、source（出處）。

範例列：{ "id": "st-1101", "vendor": "STMicroelectronics", "announced": "2026-10-05", "effective": "2026-11-01", "range": "5–10%", "scope": "通用 MCU", "source": "TrendForce 10/6" }

編輯調價事件

資料出處：調價事件整理自證券時報、經濟日報、工商時報、TechNews、國際電子商情、TrendForce、EE Times China 等公開報導。原廠多半只寄函給客戶、不對外公告，所以部分事件的幅度或範圍標為「未公布」。通路目錄價由 GitHub Actions 每天自動抓取，代理商報價與實際成交價由人工記錄，每筆都標了來源與類型。

怎麼讀這些數字：通路目錄價含通路加價，也比原廠調價函晚反應；代理商報價和實際成交價才是真正付的價格。籃子指數把每條「料號 × 來源 × 買量 × 幣別」當成獨立序列，只比較序列自己前後的變化，所以不同通路、不同幣別的價位高低不影響指數；非美元序列的變化會含匯率。
